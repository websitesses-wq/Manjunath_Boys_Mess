## 💻 Local Development

Run the application locally without any `npm install` needed:

```bash
# Clone the repository
git clone https://github.com/websitesses-wq/Rajeshwari_Boys_Mess.git

# Navigate into the folder
cd Rajeshwari_Boys_Mess

# Start the local dev server
node scripts/local-server.js
# Or using npm
npm run dev
```

Open your browser at **[http://localhost:3000](http://localhost:3000)**.

## ☁️ Deploying to Vercel

This repository is optimized for **zero-configuration instant deployment on [Vercel](https://vercel.com)**:

### Method 1: Via Vercel Dashboard (Recommended)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Select the repository **`websitesses-wq/Rajeshwari_Boys_Mess`**.
4. Leave all build settings as default (Framework Preset: **Other**, Root Directory: `./`).
5. Click **"Deploy"**! Your site will be live on a `*.vercel.app` domain in seconds.

### Method 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
